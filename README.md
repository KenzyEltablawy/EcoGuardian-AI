# EcoGuardian AI
AI Decision Support System for Climate Intervention Planning.

## Features
- Real-time environmental data (Open-Meteo)
- Heat Risk, Pollution Risk, Climate Severity
- Random Forest classifier (300 trees)
- Streamlit web interface with map
- Explainable output (Why?)

## Files
- app.py
- train_model.py
- model.pkl
- environmental_dataset.csv
- requirements.txt

## Notes
Prototype - decision support only, not a substitute for expert analysis.
